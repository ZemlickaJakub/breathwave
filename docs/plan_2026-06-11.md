## 2. MVP v1 — scope

### 2.1 Dechová cvičení (core)

Pět protokolů, každý s vizuálním pacerem (animovaná vlna/kruh), zvukovým vedením a haptikou:

1. **Koherentní dech** — 5,5 s nádech / 5,5 s výdech (nastavitelné 4–7 s). Default protokol, HRV rezonance.
2. **Box breathing** — 4-4-4-4 (nádech–zádrž–výdech–zádrž). Fokus, nervozita.
3. **4-7-8** — usínání, hluboké zklidnění.
4. **Prodloužený výdech** — 4 s nádech / 6 s výdech. Rychlé zklidnění, aktivace parasympatiku.
5. **Vlastní rytmus** — 4 fáze, každá 0–15 s, uložení vlastních presetů.

Parametry session: délka (1/3/5/10/15 min nebo ∞), zvuk on/off (tón stoupá s nádechem, klesá s výdechem), haptika on/off, gong na konci.

**Kritický požadavek:** session běží se zhasnutým displejem — zvuk a haptika pokračují (background audio). Přesně tohle byla nejčastější výtka v recenzích Resonant Breathing.

### 2.2 Meditační timer

- Délka 1–60 min, startovací a koncový gong (3 zvuky na výběr)
- Volitelné interval bells (à 5/10 min)
- Volitelný ambient (1–2 loop zvuky: oceán, ticho s šumem) — malé soubory, ať appka zůstane pod 30 MB

### 2.3 Statistiky & Health

- Streak (dny po sobě), celkové minuty, týdenní sloupcový graf
- Vše lokálně (JSON v Documents), žádný server
- **Apple Health sync:** zápis "Mindful Minutes" (HKCategoryType `mindfulSession`), opt-in toggle v nastavení. Levná feature, kterou Apple miluje — a silný argument proti rejection 4.3.

### 2.4 Ostatní

- Onboarding: 3 obrazovky max (co to umí → vyber protokol → jedem). Přeskočitelný.
- Lokalizace: **EN primární + CZ kompletní** (String Catalog). EN primární kvůli globálnímu dosahu, CZ je náš domácí trumf.
- Dark mode first (meditace večer), light mode podporován.
- Ikona: stylizovaná vlna, gradient modrá→tyrkys, žádný text.

### 2.5 Mimo scope v1 (roadmapa)

- v1.1: widgety (streak na plochu), Live Activity s odpočtem v Dynamic Islandu
- v1.2: Apple Watch companion (pacer haptikou na zápěstí — killer feature pro v2)
- v2: další jazyky (DE — tvůj DACH trh přes Malt), Shortcuts/App Intents ("Hey Siri, dechové cvičení")

**Disciplína:** do v1 NEPŘIDÁVÁME nic dalšího. Každá feature navíc = posun review a launch.

## 3. Technická architektura

### 3.1 Stack a principy

| Vrstva | Volba | Proč |
|---|---|---|
| Jazyk/UI | Swift 6, SwiftUI | Standard 2026, Claude Code v něm píše spolehlivě |
| Min. iOS | 17.0 | ~95% pokrytí zařízení, String Catalogs, Observation framework |
| Dependencies | **Žádné** (zero SPM) | Nic k auditu, žádné supply-chain riziko, rychlejší review |
| Audio | AVFoundation (`AVAudioEngine` + `AVAudioSession .playback`) | Plynulé tóny, běh na pozadí |
| Haptika | CoreHaptics (`CHHapticEngine`, custom patterns) | Nádech = stoupající intenzita, výdech = klesající |
| Persistence | Codable JSON ve `~/Documents` + UserDefaults pro settings | Pár set záznamů — SwiftData je overkill |
| Health | HealthKit, jen zápis `mindfulSession` | Opt-in, žádné čtení dat |
| IAP | StoreKit 2 (4× consumable) | Nativní, async/await API |
| Analytika | **Žádná** | "Data Not Collected" = náš marketing claim |

│   ├── BreathingSessionView.swift # pacer (vlna animace), ovládání

### 3.3 Klíčová technická rozhodnutí

1. **Pacer animace = `TimelineView` + Canvas/Shape**, řízená `BreathingEngine` state machine. Žádné `Timer.scheduledTimer` pro UI — drift. Engine počítá fáze od absolutního `CFAbsoluteTimeGetCurrent()`.
2. **Background audio:** capability *Audio, AirPlay, and Picture in Picture* + `AVAudioSession` kategorie `.playback`. Session se aktivuje jen během cvičení, deaktivuje po konci (jinak review flag 2.5.4).
3. **Zvuky generovat, ne nahrávat:** breathing tóny syntetizovat v `AVAudioEngine` (sine + envelope) → nulová licenční rizika, miniaturní binárka. Gongy = 2–3 CC0 samply v `.caf`.
4. **Streak logika v testech:** edge cases (půlnoc, timezone změna na cestách Sprinterem 🙂) — unit test first.
5. **Žádné síťové volání v celé appce** kromě otevření Safari z About. Krásně se to říká v review notes i marketingu.
